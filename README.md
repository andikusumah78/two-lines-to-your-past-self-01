# Two Lines to Your Past Self

A program that writes a two-line warning to its past self: the first line warns about one specific moment — a 2 a.m. text sent from the kitchen table on the night of a job loss — and the second line traces what that moment cost and what changed because of it. The entry is the text itself, written deterministically by `main.py` (pure Python 3.13 standard library, no network) to `entry.txt`.
